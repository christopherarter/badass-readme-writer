# Tracepick

![Build passing, 1M downloads, 100x speed, cloud ready](assets/badges.svg)

The next-generation, powerful observability platform for developers.

## Installation

Choose your package manager:

```sh
npm install -g tracepick
pnpm add -g tracepick
yarn global add tracepick
```

## Architecture

The FilterKernel coordinates the InputAdapter, ParsePipeline, PredicateRegistry, and OutputSink. The enterprise dashboard persists every event in the cloud.

## Features

- 100x faster log inspection
- Cloud dashboard
- AI root-cause analysis
- Filtering
